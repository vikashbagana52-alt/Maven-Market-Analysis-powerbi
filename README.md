# Maven Market Analysis – Power BI Dashboard

## 📊 Project Overview

Maven Market Analysis is an interactive Power BI dashboard
designed to analyze sales, profit, customers, transactions,
returns, and store performance.

## 🎯 Objectives

- Analyze overall sales and profit
- Identify top-performing products
- Compare regional sales performance
- Analyze customer segments
- Monitor transactions and returns
- Evaluate store performance
- Identify important business insights

## 🛠️ Tools Used

- Power BI
- Power Query
- DAX
- Data Modeling
- Data Visualization

## 📄 Dashboard Pages

### 1. Overview
Provides an overall summary of sales, profit, customers,
transactions, and returns.

### 2. Sales
Analyzes sales trends, regions, products, and brands.

### 3. Transactions
Analyzes transaction volume, quantity, and transaction value.

### 4. Returns
Analyzes returned quantity, return rate, and return value.

### 5. Customers
Analyzes customer segments, income groups, membership,
and customer behavior.

### 6. Stores
Analyzes store performance, store type, region, and sales.

## 💡 Key Insights

- Sales performance improved over the analyzed period.
- Regional performance varies significantly.
- A small group of products contributes substantially
  to total sales.
- Customer income segments show different purchasing patterns.
- Store performance varies by store type and region.
